# 04 — Chart feasibility

Audit date: 15 October 2026. Author: Codex, for FIT3179 Task 01 review. No charts implemented.

## Feasibility and counting

**Nine candidate advanced non-map idioms are confirmed from available data; three map idioms are conditional.** A conventional scatterplot is also feasible but is conservatively counted as basic. Dot density is unsupported as a representation of actual population locations with these sources. A fourth defensible map idiom is therefore **not currently established**.

These classifications are planning estimates, not a verified marking decision: the complete rubric was not supplied. The user's clarification establishes that maps count as advanced. “Confirmed” means a meaningful chart can be calculated from verified data; it does not certify its design or rubric classification. “Conditional” identifies a prerequisite unresolved by this audit. Connected dots and slope charts are alternatives in the proposed story and should not both be added just to increase the count. Counting nine feasible idioms does not imply nine recommended charts.

Dataset abbreviations: **B** = hospital_beds.csv; **PN/PS/PD** = population_malaysia.csv / population_state.csv / population_district.csv; **GS/GD** = administrative_1_state.geojson / administrative_2_district.geojson; **F** = facilities_master.csv; **US/UF** = bedutil_state.csv / bedutil_facility.csv; **PDF** = HEALTH_FACTS_2025.pdf. All paths are relative to the repository root. Exact filters and formulas are in report 03.

Use the PDF's complete wording when transcribing. Do not infer a sector value for perinatal, nervous-system, musculoskeletal or health-service-contact categories missing from that sector's top ten.

## Design implications for the next stage

The current evidence does not justify promising 15–17 meaningful visualisations, 11–12 accepted advanced idioms and four distinct maps simultaneously. Start with indexed growth, state rate choropleth once repaired, one change chart, hospital points once reviewed, population pyramid, an ageing comparison, and the carefully qualified cause comparison. Add only views that answer a new question. If the rubric requires a larger set, acquire the missing time-series/spatial data before expanding.

Every future chart needs an author, publication date, exact reporting year/snapshot date, source link, units, filter scope, and a concise limitation note. Use consistent state names, explicit federal-territory treatment, readable labels and aligned typography. Unsupported utilisation trends, private state maps and district access claims should not appear in the final story.
